## 📌 Projeto em destaque

### 🏢 Sistema de Gestão Empresarial

🚧 **Status: Em desenvolvimento**

Sistema de gestão empresarial desenvolvido em **Python e PostgreSQL**, com foco na aplicação prática de conceitos de engenharia de software, arquitetura em camadas e boas práticas de desenvolvimento.

O projeto contempla o gerenciamento de usuários, clientes, produtos e vendas, buscando simular funcionalidades presentes em sistemas empresariais reais.

**⚙️ Principais características:**
- Arquitetura em camadas, com separação de responsabilidades.
- Autenticação de usuários e controle de acesso baseado em permissões.
- Persistência e gerenciamento de dados com PostgreSQL.
- Implementação de regras de negócio e validações.
- Testes automatizados utilizando Pytest.

**🛠️ Tecnologias:** Python · PostgreSQL · Pytest · Git

🔗 [Acessar repositório](https://github.com/G-Braghin/Sistema-de-gestao)
